# 求职助手 Agent · Chrome 插件

在招聘网站（Boss 直聘、实习僧等）职位详情页，**一键采集页面正文**，发送到本地后端（`localhost:8000`）自动入库并进入知识库。

## 安装

1. 打开 Chrome → `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」→ 选择 `D:\job-agent\extension` 文件夹
4. 插件图标出现在工具栏

## 使用

1. 确保后端运行中（双击 `D:\job-agent\start.bat`）
2. **在招聘网站登录后**打开职位详情页
3. 点击插件图标 →「一键采集」
4. 弹出解析结果 → 自动入库

## 工作原理

```
用户浏览器（已登录招聘网站）
  └─ 点击插件 → content script 拦截当前页面
      └─ 剪掉导航/页脚/按钮/隐藏元素，只保留正文
          └─ POST http://localhost:8000/api/jd/parse-text
              └─ 走同一套 LLM 结构化解析管线 → 入库 + 知识库
```

相当于"自动帮你全选复制粘贴到解析框"，但比手动更快且不会遗漏内容。
